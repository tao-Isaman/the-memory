# 🎁 Gift mini-game — asset brief (`/gift`)

ทุกภาพในเกมเป็น **placeholder** (SVG เรียบๆ) ตอนนี้ น้องฝึกงานวาดจริงแล้ว **วางไฟล์ทับใน `public/gift/`** (ชื่อเดิม) หรือแก้ `file` ใน manifest — **ไม่ต้องแตะโค้ดเกม**

- **Manifest (ไฟล์เดียวที่ต้องแก้):** `src/lib/gift/assets.ts` — ระบุชื่อไฟล์ / ขนาด (`w`×`h` ต่อเฟรม) / จำนวนเฟรม (`frames`)
- รองรับ `.svg` / `.png` / `.webp` (โปร่งใสได้) · เกมใช้ `<img>` ธรรมดา
- `frames > 1` = sprite sheet แนวนอน N เฟรม เฟรมละ `w`×`h` (เผื่ออนิเมชัน; ตอนนี้ demo โชว์เฟรมแรก)
- รวมทุกภาพควร **< 1.5 MB** (หน้าเกมตั้งเป้า < 2MB ไม่รวมเพลง)

## ภาพที่ต้องวาด

| key | ไฟล์ | ขนาด (px) | ใช้ที่ไหน / วาดอะไร |
|---|---|---|---|
| `boxClosed` | `box-closed.svg` | 512×512 | กล่องของขวัญ**ปิด** สี่เหลี่ยม มีโบว์ — หน้า intro + ฉากแกะ (ก่อนเปิด) |
| `ribbon` | `ribbon.svg` | 512×512 | ริบบิ้น/โบว์ผูกกล่อง — ฉากแกะ (จางลง+หมุนออกทีละแตะ); ทำเป็น sprite หลายเฟรมคลายโบว์ได้ |
| `wrap` | `wrap.svg` | 512×512 | กระดาษห่อ (ลายเทศกาล) — เผื่อเอฟเฟกต์ปลิวออก |
| `boxOpen` | `box-open.svg` | 512×512 | กล่อง**เปิด**ฝา/ของขวัญเรืองแสง — ฉากเซอร์ไพรส์ |
| `sparkle` | `sparkle.svg` | 128×128 | ประกายดาว/แสงแวว — เอฟเฟกต์ตอนเปิด |
